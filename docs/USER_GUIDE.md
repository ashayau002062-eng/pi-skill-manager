# 使用指南

## 浏览与整理

搜索名称、描述、路径、分组标签和备注；「搜索正文」只查已发现 Skill 的 Markdown，不查附件。可叠加状态／分组／标签／备注筛选和排序。收藏、整理数据、排序和常用视图不影响 Pi 加载优先级。

个人备注最多 10000 字符，支持多行／Tab。分组最多 60 字符，标签最多 20 个、每个 32 字符。批量整理最多 100 项，筛选不会悄悄清除已选项；保存前检查包括筛选外目标。

分组标题旁 ✎ 修改整个已存分组名，包括未发现／其他作用域的同组记录；只修改精确名称与 `g:旧名` 的视图引用，不改成员／正文／附件／备注／收藏。目标名称已有分组或视图引用则拒绝，不合并。无意义空白组和偏好损坏时不可操作。

常用视图最多 30 个，保存搜索、状态、分组、标签、备注和排序条件。应用只读，不提交草稿，也不在启动时自动应用。失效的组／标签条件不会自动变成全量结果。

## 开关和加载诊断

列表开关修改 Pi 原生配置，不搬动 Skill。批量开关按配置文件逐个保存，不是跨文件事务；部分完成时以回执和刷新结果为准，不重放旧操作。

「加载原因」展示当前管理范围的配置解析、同名实际胜者和过滤规则，不是运行中会话遥测。内部接口不兼容、重复包身份、超限或预测与原生结果不一致时会明确不确认，不猜测规则。`disable-model-invocation` 表示仅手动调用，不等于完全禁用。

包内 Skill 编辑可能被包更新覆盖；可先复制为个人副本。项目视图需要显式 --project，不替代 Pi 的 trust 决定。

## 原文和附件

切换到「原文」可编辑原始 Markdown，保存前验证 YAML、摘要、锁和备份。保留注释、未知字段和原 LF／CRLF；单文本编辑限 1 MiB。Ctrl+S 仅在原文标签保存，其他标签不会提交隐藏草稿。草稿与历史差异只展示，不自动应用。

附件只读浏览 references／scripts／assets 等普通文件；HTML、SVG、JS 均当作文本，不执行、不联网加载。二进制、非 UTF-8、超过 1 MiB 只显示信息。跳过 .git／node_modules；链接、junction 和特殊文件拒绝。枚举 2000 项、展示 1000 节点，省略会提示，不能把空树视为没有内容。

## 创建、复制、ZIP

新建粘贴完整 SKILL.md（含 YAML name／description），不加外围代码围栏。默认个人 ~/.agents/skills；显式项目视图可选项目 .pi/skills。新建不自动补附件，也不擅自启用被配置排除的内容。

复制整个普通 Skill 目录，仅替换 YAML name，保留其他元数据、注释、正文、换行、二进制和空目录；独立 Markdown 只复制自身。已有目录／同名 Skill 拒绝覆盖。

单 Skill ZIP 导入允许直接 SKILL.md 或一层外包目录；不支持多 Skill 仓库压缩包。所有内容先验证后发布，不执行文件。多选导出最多 50 个 Skill，每个有独立子目录和清单，**不能直接使用单 Skill 导入按钮还原**。

ZIP 限 52 MiB 压缩、单文件 20 MiB、解压合计 50 MiB、1000 项、路径 512 字符／32 层；拒绝穿越、绝对路径、保留名、ADS、大小写／Unicode 冲突、链接和损坏 CRC。复制／ZIP 跳过 .git 和 node_modules，但其他隐藏文件可能包含秘密，分享前检查。

## 删除与恢复

可恢复删除仅限标准个人／显式项目 roots 内的直属 Skill 或独立 Markdown，拒绝包、链接、共享目录和自定义外部位置。目录整体归档（包括隐藏内容），不强制递归永久删除；输入 Skill 名确认后才执行。

回收站恢复到原位置，已有目标、同名、记录改变或边界异常拒绝覆盖。原设置与整理记录保留，恢复原路径后沿用旧状态。删除／恢复完成后刷新故障会明确显示完成路径，不诱导再次执行。

永久清空与单条永久删除分别先预览、输入「永久清空回收站」或「永久删除此备份」。不进入系统回收站、不可撤销、非安全擦除。只处理标准归档范围；坏记录、链接、特殊／未知内容、锁和超限保留。逐文件 unlink／空目录 rmdir，记录最后删除，部分失败有诚实回执。

清理使用 bounded 枚举、树预算和 30 秒检查点，不是能中断单 syscall 的硬截止；不是同账户恶意程序竞态的权限沙箱。不要修改归档记录来绕过限制。
